## Deviation: three stages, not two

The plan specified `generation | analysis`. Added a third, **`runtime`**, for `workers`,
`shard`, `save_structures`, `progress`.

These affect neither the scientific object nor the analysis, and calling them "analysis"
would be wrong — they are not re-specifiable analysis semantics. More importantly, worker
count **must not** enter `regeneration_key`: decoy *i* is seeded `base_seed + i`, so a
32-worker run and a 1-worker run produce bit-identical ensembles, and a key that changed
with worker count would force spurious regeneration. A test asserts runtime changes leave
the key untouched.

## Defaults now encode the A4 findings

These are the published protocol, not arbitrary choices, and several **differ from the
prototype**:

| setting | default | why |
|---|---|---|
| `decoys.identity` / `placement` | `native` / `permute` | *"we randomly shuffle the protein sequence"* — a permutation. Prototype drew i.i.d. from the composition (`frustration.py:337`). |
| `decoys.relax` | `mc` | *"A short Monte-Carlo relaxation"*. Prototype ran a chi-only MinMover (`frustration.py:364`). |
| `decoys.native_repack` | `True` | native energies *"obtained in a similar fashion by omitting the shuffling step"*. Prototype scored the crystal pose as deposited. |
| `decoys.n_decoys` | `1000` | *"1000 appropriately distributed decoys for each contact"*. Prototype used 50. |
| `contacts.seq_sep_min` | `1` (no filter) | the paper states no sequence-separation criterion. Prototype used \|i−j\| ≥ 4. |
| `graph.include_ligand_nodes` | `True` | the A4 correction. |
| `manybody.mode` | `chen_literal` | **see below** |
| `energy.exclude_fa_rep` | `True`, analysis-stage | matches the paper; now a post-hoc switch because `e_fa_rep` is stored unsubtracted. |

## Three things that need your call

1. **`manybody.mode` defaults to `chen_literal`, not `pair_retained` as plan §3.4 said.**
   Changed after A4: the exclusions are in the published Eq. 2, so `chen_literal` *is* the
   published object and is required for any reproduction claim (F3 is the near-term goal).
   It is also the degenerate one. If you would rather the tool lead with the sound formula
   and treat reproduction as the special case, this is a one-line flip. This is §10's
   remaining open question and it should be decided deliberately, not inherited.

2. **`decoys.relax="mc"` is not implemented until C8.** The default names the published
   protocol, so any run between C3 and C8 must pass `relax="min"` explicitly or it will
   fail. Deliberate: an explicit failure beats silently doing the un-published thing. Say
   the word if you'd rather default `min` until C8 lands.

3. **`n_decoys` defaults to 1000** (the paper's). At the measured ~4.4 min/decoy/core that
   is ~73 core-hours per structure. The CLI (E2) should probably require `--n-decoys`
   explicitly rather than let anyone inherit this by accident.

## A bug the tests caught

`_env_overlay` lower-cased every path segment, so `ATOMFRUST__DECOYS__REPACK_SHELL_A`
became `repack_shell_a` and was rejected by `extra="forbid"` — a correctly-spelled
variable would have failed. Several fields carry a capital Angstrom (`cutoff_A`,
`ca_cutoff_A`, `repack_shell_A`). Fixed by resolving env segments case-insensitively
against real field names, with unmatched segments passed through so genuine typos still
raise. Two regression tests added.

Also added positive controls for `check_all_fields_declare_a_stage` — without them the
"every field declares a stage" test would pass vacuously if the checker were broken.
